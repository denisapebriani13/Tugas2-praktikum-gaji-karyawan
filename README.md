# Tugas 2 - Program Hitung Gaji Karyawan

## Deskripsi
Program ini dibuat untuk menghitung total penghasilan karyawan berdasarkan golongan dan jam lembur menggunakan **statement IF**.

## Fitur Program
- Menentukan gaji pokok berdasarkan 3 golongan (A, B, C)
- Menghitung persentase gaji lembur sesuai jam kerja (1 - 5 jam)
- Menampilkan total penghasilan (Gaji Pokok + Gaji Lembur)

## Cara Menjalankan
1. Buka project di **Apache NetBeans**
2. Jalankan file `HitungGaji.java`
3. Masukkan nomor golongan (1/2/3)
4. Masukkan jumlah jam lembur

## Teknologi
- Java
- Apache NetBeans IDE
